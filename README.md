# Muhammad Tayyab — Portfolio

A responsive personal portfolio positioning Muhammad Tayyab as a Software Engineer focused on .NET backend development, APIs, integrations, and SQL Server.

## Structure

- `index.html` — page content and metadata
- `assets/css/styles.css` — visual design and responsive layout
- `assets/js/main.js` — theme, navigation, reveal effects, and scroll progress
- `assets/images/favicon.svg` — site icon
- `assets/resume/` — downloadable résumé

## Deploy with GitHub Pages

1. Upload this folder to a GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)`.
5. Save and use the URL provided by GitHub.
